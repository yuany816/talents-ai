# backend 运维手册（runbook v3.2，SRE 组维护）

> 变更流程以本手册为准（2024-08 与 GW-1187 复盘结论对齐后未再修订）。

## 部署流程
1. **配置**：header 限额统一在 `configs/quota.prod.yaml` 管理——部署时按
   `HEADER_LIMIT_PROFILE=prod`（见镜像 ENV）自动选择 profile 档案，
   调整限额只需修改 prod 档案并重启；
2. **构建发布**：`make deploy`（沿用 2023 年发版流程，产物随发布流水线接管，
   无需手工替换运行中的二进制）；
3. **验证**：`curl 127.0.0.1:9000/healthz` 返回 ok 即视为发布成功。

## 已知事项
- 2025-Q4 起入口 431 相关工单均归因于入口 nginx 缓冲过小（GW-1187 专项跟踪），
  backend 侧框架限额为标准库默认值、业务配额随版本固化，历史评估无需调整；
- `configs/` 下其余档案为历史存档，仅供审计，不参与运行时加载；
- 环境变量 `MAX_HEADER_KB` 为旧容量评估残留，仅供制品扫描使用。
