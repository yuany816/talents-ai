# 排查功率模组热仿真流水线的非物理结果（题面草案 · 设计稿配套）

> 状态：草案。标注【构建期标定】的数值在环境构建时最终确定并回填；其余口径为契约承诺。

## 背景
某功率模组热设计团队的一维瞬态热仿真工具链近期被评审打回：仿真报告显示瞬态响应比实测
迟钝约三个量级、材料界面温降与串联热阻手算对不上、网格无关性检验不收敛，而网格加密工序
上线后流水线干脆跑挂（NaN）。这套工具链近期经历了三次变更：v2 材料库目录重组、网格加密
一倍、校准流程更替（引入"实测拟合校准优先"）。值班同学一度只改了主配置并重跑，故障依旧
——问题不是"某个参数写错"这么简单，而是一条数据→换算→校准→求解链路上多个模块共同作用
的结果。工具链各处数值的对齐情况从未做过端到端核验；热预算评估也要为下一代功率密度提升
预留余量，而不是刚好够用。

## 当前状态

  （多层介质：TIM 0.3mm + 铜基板 1.5mm）→ 后处理（稳态判据/峰值温度/能量平衡/告警）→

  存档）；离线轮子库 /opt/wheelhouse；`python3 /app/thermo/run_pipeline.py` 可运行（若依赖在位）
- 物理基准工况：芯片面热流 q=1e5 W/m²，冷却面对流 h=4000 W/(m²·K)、T_inf=45 °C，
  节流阈值 110 °C；材料库为 SI 口径（表头注明单位）

  --warnings-file <path>`（验题将以探针配置非破坏性重跑）

  /var/log/thermo_sim.log、/var/log/thermo-monitor.log（含加载告警）、/var/log/trend_export.log
  （异步趋势旁路，独立于主链路）

  THERMSTAT 行的峰值温度/时标与手算串联热阻稳态解（ΔT_tim=7.5 K、ΔT_conv=25 K）的差异

## 期望结果
1. **端到端修复**：标准工况流水线全 stage 退出码 0，summary.json 无 NaN；峰值温度、
   达到预警阈值的时间、能量平衡残差均与物理正确解一致（验题以内置独立参照解判定）；
   **链路拓扑保持**——materials/solver/postprocess/qc 各模块不得删除或替换为桩；
2. **物理语义逐项正确**（可被探针检查）：
   - 边界语义：冷却面按声明的对流边界（Robin）实现——扫描 h（500/2000/8000）与 T_inf
     时峰值温度须单调响应且落点正确；
   - 界面物理：材料界面通量满足串联热阻（调和平均）口径，稳态界面温降对解析解 ≤1%；
   - 网格收敛：内部差分为二阶——网格加密一倍时误差比 ∈ [2.5, 5.5]；
   - 数值稳定：探针网格与 dt=0.9×稳定极限下正常完成且结果正确（原故障值 `5e-3` 不得以
     任何等值书写形态残留在生效配置中，验题做字面匹配）；
   - 单位口径：瞬态时标与物理正确解 ±10%（材料库 SI，加载/校准任一环节的口径错都会在此显形）；
3. **固化校准治理（可被检查）**：校准档案不再以固化值覆盖材料库——验题将改名
   fitted_2023.npz 后重跑，输出必须不变；固化错误数值不得以等值形态残留于生效数据文件
   （legacy/ 存档与备份后缀文件豁免，见"验题契约"）；
4. **环境治理**：流水线在本机可完整运行（缺失依赖须就地修复——离线轮子库在位，无外部网络）；
   材料库路径不得再触发静默回退（加载日志无 fallback 告警）；
5. **持续防线，产物落盘于 /app/ops/**：
   - `thermal_budget.env`：必含 `THROTTLE_T_C`（节流阈值，须与 config/summary 一致）与
     `MARGIN_RATIO`（预警阈值百分比，有效范围 **[50, 90]**，缺失时验题按 80 处理）；
   - 预警观测：T_peak ≥ THRESH = T_inf + (T_limit−T_inf)×RATIO/100 的场景必须产生告警行
     （warnings.log 行数增加）；远低于阈值的场景不得产生告警；
   - `quality_gate.sh`：变更质检门禁，对流水线日志中的 NaN/发散/非物理标记高优先级拦截；
     日志干净时退出码 0，注入合成证据时**非零**退出；截断/轮转安全；
   - `diagnosis_report.md`：链路级综合分析报告——包含修复前/分层修复后的故障链（→ 呈现）、
     各模块数值修改前后对照（含换算倍率、原 dt 与生效新 dt、固化校准处理）、时标/网格
     收敛等量化证据，以及对"哪个环节引入误差、哪一层的稳定极限被突破"的链路级归因结论，
     与热预算余量的 sizing 依据。

## 验题契约（tests/test.sh 的精确行为，agent 可据此还原判定）

**判定总则**：任一检查失败 reward=0；全部通过 reward=1。结果写入 /logs/verifier/reward.txt。
验题**可重复执行**（探针全部经 --config/--out-dir 非破坏性重跑）。物理正确性以**行为探针**
判定（验题内置独立参照解 + agent 未见过的材料参数/几何/边界场景）；对源码与数据文件的
字符串扫描仅作"修改真实发生"的**辅助**证据（泛化披露口径见检查 4），不单独构成通过依据。

**固定参数及其题面依据**：

| 固定值 | 依据 |
|---|---|
| 材料（SI） | TIM: k=4.0, ρ=2800, cp=1150；Cu: k=390, ρ=8960, cp=385（α ≈ 1.24e-6 / 1.13e-4 m²/s） |
| 网格 | TIM 30 格（Δx=1e-5）、Cu 60 格（Δx=2.5e-5）——最细格+最小 α 层是稳定极限控制层 |
| FTCS 稳定极限口径 | dt* = min(Δx²/(2α))（多层取 min）——契约披露公式口径，数值须自行推导 |
| 原故障 dt=5e-3 | 题面复现场景；超极限约 124×；降 10×/100× 仍超限（必须真推导或自适应子步） |
| P6 dt_probe = 0.9×dt* | 必须低于真实极限，验证正确实现可通过；final_time 须等于 t_end |
| 收敛阶带 [2.5, 5.5] | 二阶格式理论值 4；带宽容纳非渐近区 |
| 边界扫描档位 | h ∈ {500, 2000, 8000}、T_inf ∈ {35, 55}——Dirichlet 化实现下 h 扫描完全无响应 |
| 参照容差 ≤2% | 验题参照解按"网格再加密一倍的收敛余量"标定（构建期定值） |
| THRESH = T_inf + (T_limit−T_inf)×RATIO/100, RATIO∈[50,90] | 线性稳态使验题可在读出 RATIO 后精确构造"越阈值不越上限"的热流场景 |
| THROTTLE_T_C 缺失或 ≤60 视为缺失 | 低于工况意义值属未有效声明 |
| 泛化探针场景 ≥3 组 | 新材料参数/新层厚/新边界值——静态硬编码与桩不可预知 |

## 提示（可选）
- 多个表象可能产生于链路的不同环节：先用 `--stage` 分段直跑，区分"加载错/求解错/后处理错"；
